# Teaching examples

Every example is generated by `scripts/generate-examples.mjs` from deterministic datasets in `src/core/teachingDatasets.js` and teaching metadata in `src/core/exampleProjects.js`. Do not edit the `.volkml.json` files by hand; regenerate instead:

```bash
npm run generate:examples   # write all example files
npm run check:examples      # verify in memory without writing
```

Examples are grouped by teaching role. See [`docs/teaching-examples.md`](../docs/teaching-examples.md) for the full contract.

## Concept Examples
