# Teaching examples

Ready-made VOLK-ML projects, one per common ML task. Open the in-app **Examples** gallery to load them, or import the `.volkml.json` files directly.

Generated by `scripts/generate-examples.mjs`; every file is validated by `npm run check` (loads, runs the runnable pipelines in the browser, and parses both framework exports).

| File | Task | Runs in browser | Exports | Covered components |
| --- | --- | --- | --- | --- |
| `house-price-regression.volkml.json` | House price prediction | ✅ | ✅ | Data, Train/Test Split, Linear Regression, Gradient Descent, Evaluation, Predictor |
| `iris-knn-classification.volkml.json` | Iris flower classification | ✅ | — (KNN is browser-only) | Data, KNN, Classification Evaluation, Predictor |
| `spam-mlp-classification.volkml.json` | Spam detection | ✅ | ✅ | Tensor Input, Dense, ReLU, Softmax, Model Output, Cross Entropy, SGD, Supervised Trainer, Evaluation, Predictor |
| `energy-demand-mlp.volkml.json` | Energy demand forecasting | — | ✅ | Tensor Input, Dense, Model Output, Custom Loss, AdamW, Supervised Trainer, Evaluation |
| `diabetes-risk-mlp.volkml.json` | Diabetes risk prediction | — | ✅ | MLP Block, Residual MLP Block, LayerNorm, GELU, Sigmoid, Binary Cross Entropy, Adam, Supervised Trainer |
| `cat-dog-cnn.volkml.json` | Cat vs dog classification | — (image support pending) | ✅ | Tensor Input, Reshape, Conv Block (Conv2D + BatchNorm2D + MaxPool2D), Flatten, Dense, Model Output |
| `movie-recommendation.volkml.json` | Movie recommendation | — (training loop pending) | ✅ | Tensor Input, Embedding, Concatenate, Dense, Model Output |
| `sentiment-lstm.volkml.json` | Sentiment analysis | — (sequence support pending) | ✅ | Tensor Input, Embedding, LSTM, Dropout, Dense, Tanh, Model Output |

See [`docs/roadmap.md`](../docs/roadmap.md) for planned tasks and components not yet covered.
